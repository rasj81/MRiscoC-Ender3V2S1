# E3V2-SpritePro-Wifi

These are the settings for this build: an Ender-3 V2 with a Sprite Pro direct drive, a CR Touch and WiFi, running mriscoc firmware.

| Path | What's in it |
|---|---|
| `docs/PRINTER-SETTINGS.md` | Main notes: hardware, tuned settings, filament table and the tuning log |
| `docs/profiles/` | Planned variants, e.g. Project Ferrari |
| `docs/m503/` | Raw `M503` settings dumps |
| `docs/OCTOPRINT.md` | OctoPrint setup (Pi, camera, baud, G-code scripts, Shelly power) and the plugin to-do list |
| `gcode/` | Start, end, pause and layer-change G-code, settings-restore files and acceleration tests. The original stock versions are in `gcode/original/` |
| `orca-profiles/` | OrcaSlicer printer and process profiles for this build |

The general material, including the filament profiles, is one level up in `printer-config/`.
